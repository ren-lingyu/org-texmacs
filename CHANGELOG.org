* TODO v0.7.0
Standard Org Export Integration is in development. The initial standard entry,
structured handoff, STM adapter, standard context queries and Org Cite integration
are implemented; remaining work is marked below. Independent models and pure
TeXmacs document lowering remain separate from standard export preparation.

** Changed
*** Standard Org Export backend
- [X] Make =org-export-as 'texmacs= a usable standard export entry, with Org
  managing preparation, options, document selection, AST filters and Org Cite.
- [-] Replace parallel export preparation with the standard Org flow while
  preserving AST-first TeXmacs construction.

*** Public export API migration
- [-] Route interactive commands and feasible source-buffer convenience APIs
  through shared standard preparation, retaining their distinct result types.
- Interactive commands now share standard preparation for all scopes, including
  visible-only, and preserve managed buffers and guarded native file writing.
- Breaking: non-nil =org-texmacs-export-discover-bibliography= is rejected;
  configure standard Org Cite instead.  Interactive EXT-PLIST follows Org,
  while explicit source adapters retain their legacy contracts during migration.
- Final text filters feed reversible native byte output; lossy text conversion
  fails explicitly.  PDF consumes the completed native document directly.
- Preserve Org's table alignment after control-row pruning, including numeric
  column inference; unsupported width cookies fail explicitly.
- [ ] Consolidate, deprecate or remove redundant preparation and bibliography
  discovery variants, with explicit migration guidance for changed contracts.

** Added
*** Prepared AST and STM adaptation
- [X] Construct owned mathematical-document models from the final Org AST and
  a separate export context, preserving node identity and related mappings.
- [X] Recognize complete STM from preprocessing results and structurally valid
  filter-created nodes, including nodes without reliable source positions.
- [X] Deliver prepared structures and completed native documents to text, API
  and PDF consumers without repeating preparation or reparsing serialized STM.

*** Standard export semantics
- [X] Reuse Org selection, INCLUDE, SETUPFILE, macros, Babel, hooks and options
  filters, and allow legal AST insertion, deletion, movement and replacement.
- [X] Support native visible-only selection and standard reference, numbering
  and footnote queries while retaining TeXmacs labels and native structures.

*** Org Cite integration
- [X] Process citations and bibliographies through standard Org Cite using
  structured output from the existing CSL processor; explicitly reject target
  =raw= strings, including the currently unsupported =basic= processor.
- [X] Verify managed UUID citations, dynamic bibliographies and identical live
  INFO through real pinned =org-roam-organize= and CSL, including native PDF and
  HTML, without package-specific adapters.
- [X] Allow the verified unchanged CSL finalizer on native structured output;
  reject unknown/advised/replaced finalizers without probing their effects.
- [X] Preserve Org U+200B delimiters in the model and lower them to native
  zero-width spacing, avoiding visible Unicode fallback markers in Cite output.

*** Text and native PDF output
- [X] Return text from the standard exporter with verified native =.tm= byte
  conversion and supported standard output filters.
- [X] Render native PDF from the shared completed document without a =.tm=
  round trip, with explicit text-filter and Cite-finalizer compatibility rules.

*** Documentation and regression coverage
- [-] Document standard export, independent models, pure lowering and API
  migrations, update examples, and verify native output and existing contracts.

** Changed
*** Independent mathematical-document AST core
- Establish a core using native Org AST and parsed TeXmacs STM islands,
  with model validity independent of document-lowering and Org serialization
  support.
- Preserve existing =ox-texmacs= APIs and observable export behavior while
  separating core and consumer responsibilities. Standard Org Export adaptation
  remains follow-up work.

** Added
*** Independent model construction
- Construct full-document snapshots from an Org buffer, or from an existing
  Org AST and already parsed STM trees, without requiring document lowering.
- Preserve legal Org content beyond the exporter's supported subset.

*** Structured inspection
- Project Org structure and authoritative STM islands into a readable
  structural representation.
- Display that representation in an Emacs buffer.

*** Normalized Org serialization
- Serialize supported models to normalized Org text and new editable
  buffers using native Org and STM serialization.
- Report unsupported or unexpressible structures explicitly instead of
  producing lossy output.

*** Structural transformation
- Copy independent snapshots, access islands, and replace STM subtrees
  with owned data, rebuilt associations and snapshot-local locators.
- Keep structurally valid transformation results valid even outside
  serialization support, and fail their serialization explicitly.

*** Round-trip verification
- Verify structural parse/serialize round trips.
- Verify normalization idempotence.
- Verify supported transformation round trips without requiring TeXmacs
  document or PDF output.

*** Integration guidance
- Clarify standard Org Export preparation, INFO, Cite and current extension
  interoperability boundaries in the README.

[[file:CHANGELOGS/v0.5.0.org][Detailed release notes]]

** Changed
- *Breaking:* Separate noninteractive explicit-source export APIs from frontend
  commands. Update the renamed Lisp calls; the old explicit-source
  =org-texmacs-export-to-pdf= call becomes =org-texmacs-export-to-pdf-file=.
  Load =ox-texmacs= for the three interactive frontend commands.
- *Breaking:* Require explicit dispatcher menu keys. Set the complete
  =org-texmacs-export-menu-keys= option before loading =ox-texmacs= to restore
  the former =T= submenu; the default registers commands without a menu.
- *Breaking:* Run bounded hooks and native INCLUDE in full unnarrowed frontend
  exports, with source/final-text limits even without INCLUDE. Selected exports
  retain direct preparation; use explicit-source APIs for direct full conversion.
- *Breaking:* Move the Lisp libraries and Scheme service into =lisp/=; update
  manual =load-path= entries, direct file loads and installation recipes.
- *Breaking:* Replace Nix =.#default= with =.#org-texmacs= for the library.
  No default package is exported.
- *Breaking:* Preserve relative PDF file targets by default and map terminal
  =.org= targets to =.pdf= in all native consumers. Before preparation, set
  =org-texmacs-pdf-file-links-as-absolute= to =t= and
  =org-texmacs-link-org-files-as-pdf= to =nil= to retain the earlier policies.
- *Breaking:* Preserve standalone STM layout and reject known display-math roots
  mixed with prose. Use a bare STM paragraph or an explicit native block instead.
- Delegate BibTeX syntax, entry types, fields and plain formatting to TeXmacs.
  The former entry whitelist and blanket duplicate-key/field rejection are
  removed; missing or ambiguous used keys still fail explicitly.
- Preserve complete raw date timestamps instead of normalizing them to a date.
- Use Org search matching and target priorities for same-document references,
  retaining explicit errors for missing or ambiguous targets.
- Reuse untouched frontend result buffers; user edits or takeover cause a new
  result. Explicit-source buffer exports still create independent buffers.

** Fixed
- Restore native PDF hyperlink annotations and forward footnote destinations,
  including tested cross-page and repeated-reference cases.
- Use native quotation semantics for Org quote blocks.
- Recognize TeXmacs block names without case sensitivity while preserving source
  spelling and case-sensitive STM contents.
- Avoid spurious save prompts from temporary buffers used for export naming.

** Added
- Recursive formal statements with long captions, raw STM equation blocks,
  explicit figure/table wrappers and names with same-document references.
- STM fragments in direct inline footnote text, plus AST compatibility for
  anonymous caption footnotes. Stock Org parsing and native caption layout
  remain limited.
- Bare default citations in headings/TOC, basic emphasis, table cells and
  supported captions; alternate titles participate only in emitted TOC entries.
- Opt-in Org Cite bibliography discovery and restricted AST filters that can
  rewrite citation keys, including caption and alternate-title secondary data.
- Explicit native preprocessing adapters with protected STM, cross-directory
  INCLUDE, native selection parameters and literal/block inclusion forms.
- Default Scheme fontification of recognized STM and Org source editing/
  indentation for =texmacs= blocks, with a configurable editing major mode.
- Subtitle, email, language, keywords, description and creator metadata,
  independent ordered abstracts, and explicit table column alignment.
- A named =emacs= package, Fandol and native PDF GoToR renderer packages, and
  compilable English/Chinese examples with native documents and PDFs.
- Independently selectable =overlays.emacsPackages= and =overlays.texmacs=,
  configured =legacyPackages= outputs, =nix fmt= and treefmt checks.

[[file:CHANGELOGS/v0.1.0.org][Detailed release notes]]

Initial release. Requires Emacs 31.1 or later, Org 9.8 or later and a headless
TeXmacs runtime with Unix-domain socket support.

** Added
- On-demand parsing of TeXmacs special blocks into Org-compatible pseudo trees,
  with best-effort Org-managed caching and stale-source checks.
- Configurable paragraph fragment discovery and independent fragment parsing,
  with immutable source spans and explicit lifetime/configuration checks.
- A shared persistent headless TeXmacs worker, strict single-datum STM input
  validation, configurable timeouts and recovery after transport failures.
- =org-texmacs-check-setup= for capability and executable diagnostics.
- A Nix default library package and an Emacs/TeXmacs development shell.
