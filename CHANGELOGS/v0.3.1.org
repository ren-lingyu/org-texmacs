#+title: Org TeXmacs v0.3.1 Release Notes

* Overview
This is primarily a worker/session architecture release. It preserves the
public document and session APIs, supported Org syntax and Scheme protocol
while separating transport from native document operations.

* Fixed
Local request-construction errors retain their original error condition and
leave a healthy worker available. They are no longer classified as transport
failure merely because request preparation failed before sending data.

Transport, framing and malformed-response failures still stop the worker.
Native parse, encoding and session errors retain their respective
operation-specific handling.

* Compatibility
Public block, fragment, prepared-input, document and session calls need no
migration. Update all shipped Lisp libraries and the adjacent Scheme service
together in manual installations.

* Runtime requirements
Runtime requirements remain Emacs 31.1 or later, Org 9.8 or later, and headless
TeXmacs with embedded Scheme and Unix-domain sockets.

* Limitations
The release does not expand the supported document syntax or add file/PDF
export, preprocessing, preview or automatic synchronization.
