#+title: Bibliography sources

The bibliography is maintained here, alongside the examples. The example
builder tangles this BibTeX block into a temporary references.bib. Tangling copies
source text; it does not evaluate the block. The generic entry includes this same file
as literal Org source to show exactly where its bibliography came from.

Three entries demonstrate BibTeX string substitution, concatenation,
an unknown entry type and an explicitly selected cross-reference parent. They
are illustrative documentation records, not additional external publications.

#+begin_src bibtex :tangle references.bib
  @book{knuth1984,
    author = {Donald E. Knuth},
    title = {The TeXbook},
    publisher = {Addison-Wesley},
    year = {1984}
  }

  @book{euclid1956,
    author = {Euclid},
    title = {The Thirteen Books of the Elements},
    publisher = {Dover Publications},
    year = {1956}
  }

  @book{native-math,
    author = {Ada Example},
    title = {Properties of $\alpha_i$ and $\frac{a}{b}$},
    publisher = {Documentation Examples},
    year = {2026}
  }

  @string{project = {TeXmacs}}

  @book{native-parent,
    title = {Native Bibliography Demonstrations},
    publisher = {Documentation Examples},
    year = {2026}
  }

  @book{native-child,
    title = {An Explicit Cross-Reference},
    crossref = {native-parent}
  }

  @online{native-online,
    title = project # { Documentation Example},
    year = {2026},
    url = {https://www.texmacs.org}
  }
#+end_src

* Local citation style
This optional CSL fixture is retained for users who install citeproc and select
=#+cite_export: csl chapters/references.csl= explicitly. The four compiled examples
use native TeXmacs styles and do not require citeproc. CSL output may lose BibLaTeX
mathematics before the backend receives it; intact latex-fragment nodes remain
unsupported. Native mathematics in the example above follows a separate parser.
Chinese CSL output needs appropriate locale data; this fixture alone does not
establish Chinese CSL localization.

#+begin_src xml :tangle references.csl
  <?xml version="1.0" encoding="utf-8"?>
  <style xmlns="http://purl.org/net/xbiblio/csl" version="1.0" class="in-text">
    <info>
      <title>Org TeXmacs examples</title>
      <id>https://example.invalid/org-texmacs/examples</id>
      <updated>2026-11-03T00:00:00+00:00</updated>
    </info>
    <citation>
      <layout prefix="[" suffix="]" delimiter=", ">
        <text variable="citation-number"/>
      </layout>
    </citation>
    <bibliography>
      <layout suffix=".">
        <text variable="citation-number" suffix=". "/>
        <names variable="author" suffix=". "><name/></names>
        <text variable="title" font-style="italic" suffix=". "/>
        <text variable="publisher" suffix=", "/>
        <date variable="issued"><date-part name="year"/></date>
      </layout>
    </bibliography>
  </style>
#+end_src
