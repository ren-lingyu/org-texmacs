* Configuration actually used
The canonical configuration lives in shared/configuration.org. The example builder
tangles its source blocks into .el files, loads the selected configuration,
then includes those exact files below. Tangling copies code; it does not execute
blocks. Loading the selected configuration is an explicit separate build step.

** Shared page and worker settings
#+include: "common.el" src emacs-lisp

The Nix package supplies the executable path. Complete documents receive a
longer request timeout; worker startup retains its default. Page settings are
captured as native initial values. File language and description declarations
override matching global initial defaults.

** This document's profile
#+include: "profile.el" src emacs-lisp

The index retains the default generic style. The companion article uses article,
a custom headline formatter and typed internal references. The formatter adds
a test prefix, ignores task metadata and returns a literal text stree. Authored
STM in headline titles retains its source semantics with the default formatter.

This build uses TeXmacs for native output. Independent Model parsing, inspection,
STM subtree replacement and normalized Org serialization use Emacs Lisp and
Org without the TeXmacs executable.
Explicit equation and TeXmacs blocks still work.
The index retains plain references; the article explicitly enables typed
references and includes the bundled smart-ref style package. A bare link to
a numbered heading, mathematical statement, equation, figure or table uses
its target structure; an explicit link description remains unchanged.

** File links between the compiled documents
The shared configuration keeps PDF file links relative and maps a terminal .org
suffix to .pdf. Both settings are captured during document preparation. The
index's article.org link becomes article.pdf, and the article's index.org link
becomes index.pdf. These are links to sibling artifacts, not requests to compile
them; the package explicitly builds both entries.

The suffix setting also applies to saved .tm files and native sessions. Those
consumers still resolve file links against the source directory. A PDF rendered
later from a saved .tm therefore has absolute targets, unlike the direct PDF
output here. Web links and authored STM links are unaffected.

The following alternative is shown only, not loaded by the builder. Use it when
PDF file links should resolve against the source directory and retain .org:

#+begin_src emacs-lisp
  (setq org-texmacs-pdf-file-links-as-absolute t
        org-texmacs-link-org-files-as-pdf nil)
#+end_src

** Interactive settings, shown without execution
Org Src resolves Scheme for STM editing, indentation and fontification.
Emacs uses its bundled =scheme-mode= by default. The optional remapping below
requires =scheme-ts-mode= and its Scheme Tree-sitter grammar, and may also affect
other Scheme buffers. The example builder does not load this snippet:

#+begin_src emacs-lisp
  (require 'org-texmacs)
  ;; Optional, after installing the mode and grammar:
  ;; (add-to-list 'major-mode-remap-alist '(scheme-mode . scheme-ts-mode))
  ;; Set before the first require of ox-texmacs; use available menu keys.
  (setq org-texmacs-export-menu-keys
        '(:prefix ?T :buffer ?b :file ?f :pdf ?p))
  (require 'ox-texmacs)
  ;; Install citeproc and select a local style with #+CITE_EXPORT: csl STYLE.csl.
#+end_src

The build tangles a local bibliography. Standard Org Cite uses the native default
for the generic document and explicit =texmacs-native alpha= for the article.
Neither the example build nor the base package requires citeproc; install it only
for an explicit CSL selection.
Org owns preparation and recursive INCLUDE. The builder disables Babel evaluation
so the displayed code is not executed during export. Inline STM uses explicit
carriers. Private extensions are outside this configuration guide.
