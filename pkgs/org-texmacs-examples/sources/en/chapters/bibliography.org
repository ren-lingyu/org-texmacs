* Bibliography from Org
Readable notation and a structured source belong together[cite:@knuth1984].
A group can include a classical source[cite:@knuth1984; @euclid1956].
The bibliography is maintained as a BibTeX source block in references.org, not
as a separately edited .bib. This literal listing displays the canonical source:

#+INCLUDE: "references.org" src org

The final illustrative records exercise native string declarations and
concatenation, an @online entry and a cross-reference to an explicitly cited
parent[cite:@native-child; @native-parent; @native-online]. These are documentation
examples, not claims about external publications. TeXmacs parses and formats the
selected records in its native plain style. Unknown entry types use native
fallback formatting; fields such as @online URL may be ignored. This is not full
BibLaTeX/Biber compatibility, and an uncited cross-reference parent is not added
automatically.
