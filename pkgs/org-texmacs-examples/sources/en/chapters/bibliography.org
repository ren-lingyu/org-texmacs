Readable notation and a structured source belong together[cite:@knuth1984].
A group can include a classical source[cite:@knuth1984; @euclid1956].
The bibliography is maintained as a BibTeX source block in references.org, not
as a separately edited .bib. This literal listing displays the canonical source:

#+include: "references.org" src org

The final illustrative records exercise BibTeX string declarations and
concatenation, an @online entry and a cross-reference to an explicitly cited
parent[cite:@native-child; @native-parent; @native-online]. These are documentation
examples, not claims about external publications. Standard Org Cite and citeproc
parse the bibliography and format structured Org output using the local references.csl style. TeXmacs lowers and renders that
prepared structure; it does not run the retired native bibliography preparation.
These inputs do not establish complete BibLaTeX/Biber compatibility. The selected
CSL style determines which fields appear.

** Citations in formatted text and tables
The heading and its alternate table-of-contents title above both contain a
citation. Citations also remain structured inside *bold text [cite:@knuth1984]*,
/italic text [cite:@euclid1956]/, _underlined text [cite:@knuth1984]_ and
+struck-through text [cite:@euclid1956]+. These phrases demonstrate placement,
not different citation styles.

The following source summary uses citations in table cells and in both the
long and short caption. The printed table shows the long caption; the short
caption is retained in the native document for styles that use it.
