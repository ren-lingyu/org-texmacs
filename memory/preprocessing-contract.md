## Dependencies, resources and limits

Root visiting identity regular or absent; source directory and resource base agree.
All actual included files share lexical root directory. Existing original relative
STM paths therefore keep the common base; Org link relocation alone is insufficient
for cross-directory STM. Cross-directory resource encoding is separate design.
Capture actual selected/nested file dependencies lazily, once per normalized path,
return copies on every native read. Out-of-selection nested include files not read;
native extraction of needed outside-selection footnotes may consume captured text.
No file-local eval. UTF8 regular <=64KiB/file; <=8 nested levels, <=32 expansions
including root; root plus unique acquired original texts <=256KiB, protected root
and final working text <=256KiB. Reject wrappers/unmatched/unsupported parameters,
zero minlevel, tilde/remote/URL/control paths, symlinks/physical aliases/cycles/budgets.
Native invalid location/selection errors become documented document errors.

Owned receipts observe attributes/inode/device and byte hash. Original source,
configuration/hooks, explicit data and dependencies checked across acquisition,
preprocessing callbacks, native waits and final document/bytes return. Optional
bibliography discovery once over composed masked working Org, unchanged explicit
text priority and Phase3 receipts. No retry, text replacement, rediscovery/filter
replay, output file publication, atomic FS/DB or ABA guarantee. No real package/DB
compatibility, GUI rendering, wrappers, cross-directory or general export claim.
