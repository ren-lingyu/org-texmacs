# E2b: structured source consumers and parallel preparation retirement

## Controlling user decision: Org structure priority

The user supersedes the earlier conditional early-protection gate. Standard Org
preprocessing/pruning/options/AST filters/Cite determine the effective AST. STM
has no precedence over headings, paragraphs, keywords or blocks. Accept complete
multiline STM within one supported owner; never search later structures for a
missing close. Native blocks use their final valid Org node/effective contents.
Synthetic nodes need complete structured input or explicit properties, not original
positions. Final results may be changed, expanded, deleted or generated by Org.
Accept valid results; propagate Org errors; reject identifiable incomplete,
cross-boundary or unassociated candidates. Do not restore original candidates or
require byte fidelity. Independent parsing/model/transform/pure lowering stay.
This is an architecture decision, not a temporary test waiver.

Stop generic early parser development, original-content protection, INCLUDE
interception, cross-heading repairs and source reparse/parallel preparation.
No such parser was added to production. Successful limited probes do not justify
adoption. The widened cross-heading variant is rejected for this work. Arbitrary
literal containers/new syntax require a separate future decision.

Narrowed validation: single/multiline STM in effective paragraph/inline-note/native
blocks and incomplete/cross-boundary rejection; ordinary/recursive/ranged/leveled
INCLUDE, macros, Babel, SETUPFILE/hooks and Org-looking STM strings under actual
Org results; legal AST insertion/deletion/movement/replacement and positionless
STM, correct ownership without resurrection/dangling mappings; pure model/lowering,
native serialization/PDF, standard Cite/actual extension, source isolation and no
old preparation dependency. Reuse maintained coverage; add tests only for actual
changes, never rejected parser designs.

consumer. Keep model parsing/construction/inspection/transformation/normalized Org
serialization independent; keep pure input construction/document lowering. Retire
